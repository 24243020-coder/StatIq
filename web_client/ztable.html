How to read this table

This table gives the area between the mean (Z = 0) and a positive Z value — i.e. P(0 ≤ X ≤ Z).
To find the area for Z = 1.96: find row 1.9 → column 0.06 → value = 0.47500
To get the left-tail probability P(X ≤ Z): add 0.5 to the table value (since the left half = 0.5).
For negative Z: the table is symmetric — P(0 to −Z) = P(0 to Z). Left tail of −Z = 0.5 − table value.
